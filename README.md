# CloudCapsule

A cloud-native module lifecycle management platform built with React,
Python, PostgreSQL, Docker, Terraform, and AWS.

## Project Goals

- Manage application modules and environments.
- Track deployments and application health.
- Integrate with real AWS services.
- Demonstrate security, scalability, monitoring, and recovery.
- Support reproducible deployment and safe teardown.

## Development Status

Currently in local development.

AWS infrastructure will only be deployed after reviewing and approving
the architecture and cost estimate.

## Technology Stack

- Frontend: React and TypeScript
- Backend: Python and FastAPI
- Database: PostgreSQL
- Containers: Docker and Docker Compose
- Infrastructure as Code: Terraform
- Cloud: AWS (planned)

## Security

Never commit credentials, API keys, real .env files, or Terraform state.
